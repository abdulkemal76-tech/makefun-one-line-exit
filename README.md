An entry for the make.fun bounty [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1): a program that writes the funniest single-line resignation letter it can, reading like a letter a person could actually send, to `/output/entry.txt`.

## Run

```sh
python3 -P -s main.py
```

## The line

> I am resigning effective Friday. The 7 a.m. standup has eaten my soul, and I'd like it back before it schedules a follow-up.

One line, 124 characters. A named workplace detail (the 7 a.m. standup), a surprise turn at the end, and nothing else.
